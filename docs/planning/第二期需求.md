## 1. 写作工作台 [优先级: P0]

### 1.1 概述 ✅ 已部分实现
写作工作台已实现在 `WritingScreen.kt`（657 行）和 `WritingViewModel.kt`（408 行）中，包含"编辑"和"对话"两个可切换的 Tab。"编辑"Tab 功能完整，"对话"Tab 为占位状态。

### 1.2 整体布局 — 已实现

```
┌──────────────────────────────────┐
│  顶部栏: 返回 + 项目标题 + 保存状态  │  ← WritingTopBar
├──────────────────────────────────┤
│  [Tab] 编辑    [Tab] 对话         │  ← WritingTabRow (Material 3 TabRow)
├──────────────────────────────────┤
│  编辑 Tab 内容:                   │
│  ┌ 章节列表（可折叠侧边栏）        │  ← ChapterListPanel
│  ├───────────────────────────────┤
│  │ MarkorEditor (主区域)          │  ← Markdown 语法高亮
│  └───────────────────────────────┤
│                                   │
│  对话 Tab 内容:                   │
│  ┌ 对话占位提示                    │  ← DialogPlaceholder ("功能开发中")
│  └───────────────────────────────┤
├──────────────────────────────────┤
│  状态栏: 章节进度 + 字数统计       │  ← WritingStatusBar
└──────────────────────────────────┘
```

- **进入方式**：从底部导航栏"写作"标签进入（`MainScreen.kt` — `Screen.Writing` 路由）
- **无项目状态**：引导用户先选择或创建一个项目（`NoProjectContent` Composable）
- **当前章节指示器**：顶部栏 `WritingTopBar` 显示当前编辑的章节名称

### 1.3 编辑 Tab — 已实现

#### 1.3.1 章节列表 ✅
- **数据源**：从 `project.storagePath` + `正文/` 目录读取所有 `.md` 文件
- **解析**：使用 `ChapterFileHelper.parseChapterContent()` 读取 YAML Front Matter 元数据（title/order/volume/summary）
- **排序**：按 `order` 字段排序
- **显示**：`ChapterListItem` — 章节标题、volume 标签、摘要行
- **操作**：
  - 点击章节 → 加载到 `MarkorEditor`
  - 上移/下移按钮 → 交换两个文件的 `order` 值
  - 删除按钮 → 确认对话框后删除
  - 新建按钮 → 弹出对话框输入章节标题

#### 1.3.2 章节编辑器 ✅
- **编辑器**：使用 `MarkorEditor` Composable（`Markdown` 模式语法高亮）
- **配置**：通过 `AppEditorConfig` 从用户设置读取字体大小/类型
- **自动保存**：
  - 按 `UserSettingsRepository` 中的自动保存间隔定时保存
  - 支持即时保存模式（`autoSaveImmediately` flag）
  - 切换章节时自动保存当前章节
- **保存状态指示**：`WritingStatusBar` 显示"已保存"/"保存中"/"● 未保存"
- **字���统计**：实时显示当前章节字数（通过 `editorContent.length` 简单计数）

#### 1.3.3 章节元数据（YAML Front Matter）✅
- **工具类**：`util/ChapterFileHelper.kt`（69 行）
- **数据类**：`ChapterMeta(title, order, volume, summary)`
- **方法**：
  - `parseChapterContent(content)` → `Pair<ChapterMeta, String>`（元数据 + 正文）
  - `buildChapterContent(meta, body)` → 完整 `.md` 文件内容
  - `extractTitleFromBody(body)` → 从正文提取首个 # 标题
- **编辑器行为**：加载时剥离元数据 → 编辑器只显示正文 → 保存时重新组合

#### 1.3.4 编辑与对话联动 ⏳ 未实现
- 选中文本发送到对话：未实现
- AI 回复插入到章节：未实现
- 上下文联动：未实现
