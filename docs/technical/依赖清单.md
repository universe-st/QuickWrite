# QuickWrite 第一期依赖清单

已完成以下依赖的引入，支持第一期需求的开发：

## 1. UI 框架和组件
- **Jetpack Compose**: `androidx.compose.*` (BOM 管理)
- **Material 3**: `androidx.compose.material3`
- **导航组件**: `androidx.navigation:navigation-compose`
- **图片加载**: `io.coil-kt:coil-compose`

## 2. 架构和数据层
- **数据库**: `androidx.room:room-runtime`, `androidx.room:room-ktx`, `androidx.room:room-compiler` (KSP)
- **本地存储**: `androidx.datastore:datastore-preferences`
- **ViewModel**: `androidx.lifecycle:lifecycle-viewmodel-compose`

## 3. 网络和服务
- **HTTP 客户端**: `com.squareup.retrofit2:retrofit`, `com.squareup.retrofit2:converter-gson`
- **HTTP 拦截器**: `com.squareup.okhttp3:okhttp`, `com.squareup.okhttp3:logging-interceptor`
- **协程**: `org.jetbrains.kotlinx:kotlinx-coroutines-android`

## 4. 工具库
- **JSON 解析**: `com.google.code.gson:gson`
- **日志**: `com.jakewharton.timber:timber`

## 5. 编译工具
- **KSP**: `com.google.devtools.ksp` (替换 kapt, 用于 Room)

## 6. 测试框架
- **单元测试**: `junit:junit`
- **Android 测试**: `androidx.test.ext:junit`, `androidx.test.espresso:espresso-core`
- **Compose UI 测试**: `androidx.compose.ui:ui-test-junit4`

## 技术架构完整度
- ✅ **MVVM 架构支持**: ViewModel + Compose + Flow
- ✅ **本地数据持久化**: Room + DataStore
- ✅ **网络请求**: Retrofit + OkHttp
- ✅ **依赖管理**: 使用 version catalog (libs.versions.toml)
- ✅ **协程异步**: Kotlin 协程支持
- ✅ **现代 UI**: Jetpack Compose + Material 3
- ✅ **编译优化**: KSP 替代 kapt

## 未包含但计划中的依赖
- **AI 服务 SDK** (根据实际选择的 AI 提供商)
- **文件加密库** (用于敏感数据)
- **权限管理库** (用于文件访问权限)
- **崩溃报告** (如 Firebase Crashlytics)

所有依赖已通过 Gradle 构建验证，项目结构完整，可以开始第一期功能的开发。
