## 1. 写作工作台 [优先级: P0]

### 1.1 概述
将底部导航栏的"写作"标签页改造为统一的写作工作台，包含"编辑"和"对话"两个可切换的 Tab。用户在同一页面的"编辑" Tab 下进行章节写作，切换到"对话" Tab 即可与 AI 助手交流，无需离开当前页面。

### 1.2 整体布局

```
┌──────────────────────────────────┐
│  顶部栏: 当前项目标题 + 操作按钮   │
├──────────────────────────────────┤
│  [Tab] 编辑    [Tab] 对话         │  ← Tab Row（滑动/点击切换）
├──────────────────────────────────┤
│                                  │
│  编辑 Tab 内容:                   │
│  ┌ 章节列表（左侧/抽屉）          │
│  │  或                           │
│  └ 编辑器（主区域）               │
│                                  │
│  ———— 或 ————                    │
│                                  │
│  对话 Tab 内容:                   │
│  ┌ 对话历史列表                   │
│  │  或                           │
│  └ 当前对话（聊天气泡）           │
│                                  │
├──────────────────────────────────┤
│  底部输入区（对话 Tab 可见）       │
└──────────────────────────────────┘
```

- **进入方式**：从底部导航栏"写作"标签进入
- **项目上下文**：当前选中的项目（从项目列表或详情页设定）
- **Tab 切换**：使用 Material 3 `TabRow`，支持点击和左右滑动切换
- **无项目状态**：引导用户先选择或创建一个项目
- **当前章节指示器**：顶部栏显示当前正在编辑的章节名称

### 1.3 编辑 Tab

#### 1.3.1 章节列表
- **列表展示**：展示当前项目 `正文/` 目录下的所有 `.md` 文件
  - 按文件名排序（支持拖拽排序）
  - 显示章节标题、字数统计、最后修改时间
  - 支持章节序号自动编号（第一章、第二章...）
- **空状态**：尚无章节时的引导（"创建第一章"按钮）
- **批量操作**：长按多选 + 顶部操作栏（删除、移动、合并）
- **交互方式**：
  - 点击章节 → 在右侧/下方展开编辑器
  - 点击新建按钮 → 弹出新建对话框（含模板选择）

#### 1.3.2 章节编辑器
- **编辑器集成**：使用 `MarkorEditor` Composable 作为核心编辑组件
  - Markdown 语法高亮
  - 行号显示
  - 自动格式化
  - 撤销/重做支持
- **编辑器配置**：通过 `EditorConfig` 接口注入
  - 字体大小（从用户设置读取）
  - 字体类型（从用户设置读取）
  - 深色模式适配
  - 拼写检查开关
- **章节操作**：
  - 新建章节（选择模板或空白）
  - 保存（自动保存 + 手动保存）
  - 重命名章节
  - 删除章节（二次确认）
  - 章节排序（拖拽或上移/下移按钮）
- **字数统计**：实时显示当前章节字数
- **章节模板**：
  - 空白章节
  - 开端模板（`# 第X章\n\n## 场景\n\n`）
  - 发展模板（`# 第X章\n\n## 过渡\n\n`）
  - 高潮模板（`# 第X章\n\n## 冲突\n\n`）
  - 结局模板（`# 第X章\n\n## 收束\n\n`）

#### 1.3.3 编辑器状态
- **保存状态指示**：
  - 已保存（绿色指示）
  - 未保存更改（黄色指示，显示"●"）
  - 保存中（旋转指示器）
- **自动保存**：
  - 按用户设置的间隔自动保存
  - 切出页面时自动保存
  - 应用进入后台时自动保存
- **草稿恢复**：异常退出后恢复未保存内容

#### 1.3.4 章节元数据（YAML Front Matter）

每个章节 `.md` 文件头部包含 YAML 格式的前置元数据，编辑器不可直接编辑此部分：

```markdown
---
title: "第一章：初入异世"    # 章节标题
order: 1                     # 排序序号（用于章节排序）
volume: "第一卷：风云初起"   # 所属分卷（可选）
summary: "主角醒来发现自己穿越到了异世界"  # 内容摘要（可选）
---

# 第一章：初入异世

（正文内容...）
```

- **元数据字段说明**：
  - `title`：章节标题，显示在章节列表中
  - `order`：排序序号，用于章节上下移动排序和列表排列
  - `volume`：分卷信息，用于按卷分组显示（可选）
  - `summary`：内容摘要，显示在章节列表的次要文本中（可选）
- **编辑器行为**：
  - 加载文件时自动剥离元数据部分，正文内容传入 `MarkorEditor`
  - 保存时 ViewModel 自动重新组合元数据 + 正文写入文件
  - 用户无法在文本编辑器中直接编辑元数据
- **工具类**：`util/ChapterFileHelper.kt` 提供 `parseChapterContent()` 和 `buildChapterContent()` 方法
- **章节排序**：通过交换两个文件的 `order` 值实现排序，使用上下移动按钮操作

#### 1.3.5 编辑与对话联动
- **发送到对话**：选中文本 → 右键/长按菜单 → "发送到 AI 对话" → 自动切换到"对话"Tab 并填充输入框
- **插入 AI 结果**：在"对话"Tab 中点击 AI 回复 → "插入到当前章节" → 切换到"编辑"Tab 将内容插入光标位置
- **上下文联动**：切换到"对话"Tab 时，自动将当前章节内容作为对话上下文

### 1.4 技术要点
- 文件存储：`{projectId}/正文/{章节标题}.md`
- 章节排序：使用文件名前缀数字序号 + 可选的独立排序索引文件
- 编辑器配置从 `UserSettingsRepository` 读取
- 使用 `FileManager` 进行所有文件操作

### 1.5 验收标准
- [ ] 写作工作台有"编辑"和"对话"两个 Tab 可切换
- [ ] 可以创建、编辑、保存、删除、重命名章节
- [ ] 编辑器正确应用字体和主题设置
- [ ] 自动保存按配置间隔工作
- [ ] 字数统计准确
- [ ] 章节列表正确反映文件系统状态
- [ ] 选中文本可发送到对话，AI 回复可插入到章节

## 2. 文档管理系统 [优先级: P1]

### 2.1 概述
为项目文件系统提供可视化管理界面，让用户可以直接浏览和操作项目目录结构中的文件。

### 2.2 功能需求

#### 2.2.1 文件浏览器 [新增 Screen]
- **进入方式**：从项目详情页点击"文件管理"进入
- **目录树展示**：
  - 以树形结构展示项目所有目录
  - 可展开/折叠子目录
  - 当前路径面包屑导航
- **文件列表**：
  - 显示文件名、文件类型图标、大小、修改时间
  - 按类型分组（目录优先）
  - Markdown 文件显示字数预览
- **文件操作**：
  - 点击文件：使用对应编辑器打开
  - 长按文件：弹出操作菜单（重命名、删除、移动、复制）
  - 新建文件：选择目录 + 输入文件名
  - 新建目录：在当前目录下创建子目录
  - 删除：二次确认
  - 重命名：内联编辑

#### 2.2.2 快速文件导航
- **最近文件**：显示最近打开的文件列表（来自 `recent_files` 表）
- **快捷入口**：在详情页直接展示各目录的文件数量
- **文件搜索**：按文件名搜索项目文件

#### 2.2.3 文件预览
- **Markdown 预览**：只读模式渲染 Markdown 内容
- **纯文本预览**：简单文本展示
- **文件信息**：显示文件路径、大小、创建/修改时间、字数

### 2.3 技术要点
- 文件列表完全基于文件系统扫描（`FileManager.getDirectoryContents()`）
- 最近文件使用数据库表 `recent_files` 追踪（需要新建 Entity + DAO）
- 文件操作全部通过 `FileManager` 执行

### 2.4 验收标准

- [ ] 可以新建、重命名、删除文件和目录
- [ ] 最近文件列表正确更新

## 5. AI 对话与写作辅助 [优先级: P1]

### 5.1 概述
实现完整的 AI 对话和写作辅助功能，包括网络请求层、对话界面、上下文感知和一致性检查。AI 对话界面位于写作工作台的"对话"Tab 中，与编辑器同屏切换。

### 5.2 功能需求

#### 5.2.0 对话 Tab 布局

```
┌──────────────────────────────────┐
│  对话 Tab                         │
├──────────────────────────────────┤
│  ┌─ 上下文指示条 ──────────────┐  │
│  │ 📄 当前参考: 第三章 光明顶之战 │  │  ← 显示当前引用的文档上下文
│  │ [切换上下文范围 ▾]          │  │
│  └─────────────────────────────┘  │
│                                    │
│  ┌─ 消息列表 ──────────────────┐  │
│  │                              │  │
│  │  [用户气泡]                  │  │  ← 右对齐，灰色背景
│  │    帮我续写这一段...          │  │
│  │                              │  │
│  │  [AI 气泡]                   │  │  ← 左对齐，主题色背景
│  │    以下是续写建议：           │  │

│  └─────────────────────────────┘  │
│                                    │
│  ┌─ 输入区 ────────────────────┐  │
│  │  [/续写 光明顶的场景描写...]  │  │  ← 输入框 + 快捷指令
│  │  [📎] [🎤] [发送 ➤]         │  │
│  └─────────────────────────────┘  │
└──────────────────────────────────┘
```

#### 5.2.1 网络请求层实现 [基础设施]
- **Retrofit 服务接口**：
  ```kotlin
  interface AiApiService {
      @POST("chat/completions")
      suspend fun sendChatMessage(
          @Header("Authorization") apiKey: String,
          @Body request: ChatCompletionRequest
      ): ChatCompletionResponse
  }
  ```
- **OkHttp 客户端配置**：
  - 超时设置（连接 30s、读取 60s）
  - 日志拦截器（仅 Debug 模式）
  - 错误重试机制（最多 3 次，指数退避）
- **请求/响应模型**：
  - `ChatCompletionRequest`：model, messages, temperature, max_tokens, top_p, frequency_penalty, presence_penalty, stream
  - `ChatCompletionResponse`：id, object, created, model, choices, usage
  - `Message`：role (system/user/assistant), content
  - `Choice`：index, message, finish_reason
  - `Usage`：prompt_tokens, completion_tokens, total_tokens
- **流式响应支持**：
  - SSE (Server-Sent Events) 流式解析
  - 逐 token 显示生成内容
  - 支持中断生成

#### 5.2.2 AI模型服务管理器 [新增 Service]
- **模型路由**：根据配置选择对应 API 端点
- **API 密钥管理**：从 `AiModelConfigEntity` 读取密钥
- **请求构建**：根据当前配置构建请求参数
- **错误处理**：网络错误、API 错误、超时的统一处理
- **Token 计数追踪**：记录每次对话的 token 消耗

#### 5.2.3 AI 对话界面 [写作工作台·对话 Tab]
- **位置**：底部导航"写作"标签 → "对话"Tab
- **入口方式**：
  - 直接点击底部导航"写作"进入 → 默认显示"编辑"Tab
  - 点击"对话"Tab 切入对话
  - 从编辑器中选中文本 → 右键/长按菜单 → "发送到 AI 对话" → 自动切到"对话"Tab
- **界面组成**：
  - **上下文指示条**：显示当前为对话提供的参考文档信息
    - "📄 当前参考：{当前章节名}" 或 "📄 当前参考：全部设定"
    - 可点击切换上下文范围（仅当前章节 / 当前章节+人物设定 / 全部设定）
  - **消息列表**：聊天气泡式布局（用户消息右对齐、AI 回复左对齐）
    - 消息列表自动滚动到最新
    - 支持 Markdown 渲染（AI 回复中的代码块、列表等）
    - 长按消息可复制、重新发送或插入到章节
  - **输入区**：输入框 + 发送按钮 + 快捷指令前缀
- **对话管理**：
  - 新建对话（清空当前对话，开始新的上下文）
  - 历史对话列表（按项目分组，从数据库读取）
  - 切换历史对话
  - 删除对话历史
  - 导出对话记录
- **输入模式**：
  - 自由输入
  - 快捷指令（`/续写`、`/描写`、`/对话`、`/设定`、`/检查`）
  - 自动补全快捷指令（输入"/"时弹出指令列表）

#### 5.2.4 上下文感知写作辅助 [核心功能]
- **自动上下文构建**：
  ```kotlin
  data class WritingContext(
      val projectId: String,
      val currentChapter: String?,         // 当前章节内容
      val recentChapters: List<String>,    // 最近3章内容摘要
      val mentionedCharacters: List<CharacterInfo>,  // 本章涉及人物
      val currentTimeline: TimelinePoint?,  // 当前时间点
      val relevantSettings: List<String>,   // 相关设定摘要
      val writingRules: String             // 写作规范
  )
  ```
- **上下文选择策略**：
  - 续写：当前章节前 2000 字 + 本章涉及人物设定 + 当前时间线
  - 描写：目标地点设定 + 当前时间线 + 相关章节描写参考
  - 对话：参与人物设定 + 人物关系 + 当前场景背景
  - 情节建议：最近 5 章摘要 + 主要人物现状 + 未解决伏笔
- **Token 预算管理**：
  - 根据模型 max_tokens 动态分配
  - 系统提示词固定占用（约 500 tokens）
  - 上下文按优先级分配剩余预算
  - 超出时自动摘要压缩

#### 5.2.5 写作辅助功能 [编辑 Tab · AI 建议面板]
- **位置**：编辑 Tab 底部 Drawer 或侧边面板，可通过按钮展开/收起
- **AI 建议面板**：
  - 续写建议：基于当前内容生成 3 个续写方向
  - 描写润色：选中文本的描写增强
  - 对话优化：对话内容的自然度优化
  - 情节转折：基于当前章节的建议
- **建议操作**：
  - 点击建议内容 → 直接插入到编辑器光标位置
  - 点击"在对话中展开" → 切换到"对话"Tab 将建议作为上下文继续对话
- **一致性检查**：
  - 人物一致性：检查是否与人物设定文档一致
  - 时间线一致性：检查事件顺序是否正确
  - 设定一致性：检查世界观设定是否冲突
- **快捷操作**（编辑器内选中文本后的浮动菜单）：
  - 选择文本 → 浮动菜单 → "AI 优化" / "AI 续写" / "发送到对话"
  - 插入位置 → 浮动菜单 → "AI 生成下一段"

#### 5.2.6 系统提示词管理
- **自动生成**：基于项目文档动态生成系统提示词
- **提示词结构**：
  ```
  1. 角色定义（专业写作助手）
  2. 项目信息（标题、作者、类型、进度）
  3. 文档结构说明（目录和文件索引）
  4. 写作规范（来自配置/写作规范.md）
  5. AI 指令（来自配置/AI指令.md）
  6. 当前上下文（当前章节、最近章节摘要）
  7. 工作原则（准确性优先、主动探索、一致性检查）
  ```
- **更新时机**：
  - 项目创建时生成
  - 重要文档变更时更新
  - 用户手动刷新
  - 每次对话开始时动态构建

#### 5.2.7 AI 对话数据库

| SSE 在 Android 上的兼容性 | 流式响应失败 | 低 | 使用标准 HTTP + chunked transfer |
| 上下文 Token 超限 | AI 响应质量下降 | 中 | 实现智能摘要和优先级裁剪 |
| Android 文件权限限制 | 导出到外部存储失败 | 中 | 使用 SAF (Storage Access Framework) |
| EncryptedSharedPreferences 兼容性 | 密钥加密失败 | 低 | 降级到基础加密方案 |

### 11.2 进度风险

| 风险 | 缓解措施 |
|------|----------|
| AI 功能开发周期不确定 | 优先实现核心对话功能，流式解析和高级上下文作为增强 |
| 测试覆盖时间不足 | 优先覆盖 ViewModel 和 UseCase |
| 设定管理界面量大 | 实现通用 CRUD 框架，4类设定共用组件 |
